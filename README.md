# זרע — Sperm Bank App

אב־טיפוס בעברית ומימין לשמאל לניהול תורמים, מנות, נתרמות, אישורים וחסימות בבנק זרע בבית חולים.

**גרסת הדגמה בלבד: אין להזין מידע אמיתי של תורמים, מטופלות או ילדים.** הנתונים נשמרים ב-localStorage בדפדפן בלבד. אין שרת, בקרת הרשאות אמיתית, הפרדת מוסדות או חיבור למשרד הבריאות.

## הפעלה

דרושים Node.js 20 ומעלה ו-Python 3. אין חבילות להתקנה.

```sh
npm run dev
```

פתחו http://localhost:4173 בדפדפן. אפשר גם להגיש את תיקיית dist בכל שרת קבצים סטטיים.

```sh
npm run check
npm test
```

## מה כלול

- תמונת מצב עם מדדים מחושבים, מלאי והתראות.
- תיק תורם: קוד פנימי, כינוי, מקור מקומי / יבוא / העברה בישראל, קוד ובנק מקור, תאריכי קליטה ופרטי הדגמה חסויים.
- קליטת מנות עם מזהים נפרדים, אצווה, תאריך תרומה והקפאה, מיקום, שיוך לנתרמת ושחרור מהסגר מתועד.
- טיפולי IUI, IVF ו-ICSI המקושרים למנה, נתרמת ומחזור טיפול; מניעת שימוש כפול ורישום שימוש בתורם חסום או ללא אישור תקף.
- אישורים וחסימות עם החלטה, תאריך קבלה, תוקף, סיבה ואסמכתה; שחרור חסימה מפורש ונפרד.
- קליטת עדכוני משרד הבריאות מ-CSV עם תצוגה מקדימה ובדיקת נתונים; אינה תקשורת עם משרד הבריאות.
- נתרמות פעילות והיסטוריות, מלאי עוברים, לידות ומעקב בריאותי שניתן לעדכן.
- תשלומים לתורם מקומי והעברות נכנסות / יוצאות ברמת מזהי מנות.
- דוחות CSV לתקופה, הדפסה, גיבוי JSON ושחזור עם בדיקות עקביות.
- התאמת שם המוסד, היחידה והצבע המוביל.

## עריכה ופיתוח

| קובץ | תפקיד |
| --- | --- |
| dist/index.html | מעטפת HTML בעברית ו-RTL |
| dist/style.css | עיצוב, התאמה למסכים והדפסה |
| dist/app.js | נתוני הדגמה, מסכים, טפסים וכללי עבודה |
| tests/workflows.test.cjs | בדיקות תהליכים, חסימות ועקביות נתונים |
| docs/architecture.md | מבנה נתונים, גבולות הגרסה והמשך פיתוח |

מבנה הרשומות מרוכז בפונקציית seed. ההגדרות מתוך האפליקציה משפיעות על המכשיר הנוכחי בלבד. שינוי נתוני פתיחה אינו משנה גיבוי שכבר נשמר בדפדפן; אפשר לאפס דרך הגדרות לאחר ייצוא גיבוי.

## לפני שימוש מוסדי

יש לתכנן בסיס נתונים ושרת מאובטחים, הרשאות לפי תפקיד ומוסד, כספת פרטים מזהים נפרדת, יומן ביקורת בלתי ניתן לשינוי, גיבויים מרכזיים ושחזור, ניהול מסמכים, בקרת מקביליות, זיהוי ברקוד וחיבור רשמי למקורות מאושרים. נדרשת בדיקה עם מערכות המידע, אבטחת המידע והגורמים המקצועיים של בית החולים. מגבלות תורם ומכסות ארציות לא הוגדרו באב־הטיפוס.

ההסתרה החזותית של פרטי תורם ובדיקות החסימה בצד הדפדפן אינן מנגנון אבטחה לייצור. מאגר זה ציבורי; אין להעלות אליו נתונים קליניים, מסמכים אמיתיים, גיבויים או סודות.
